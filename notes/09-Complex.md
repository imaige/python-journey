# Python Complex Type

## What is complex?
Python provides the `complex` data type for complex numbers.

```python
x = 3 + 4j
```

`j` represents the imaginary part.

## Create complex numbers
```python
x = complex(7, 9)
print(x)  # (7+9j)
```

## Real and Imaginary Parts
```python
x = 10 + 6j
print(x.real)  # 10.0
print(x.imag)  # 6.0
```
