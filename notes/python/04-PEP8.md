# PEP 8 — Python Style Guide

## What is PEP 8?

PEP 8 is the official style guide for writing readable and consistent Python code.

Its goal is not to change how the program works. Its goal is to make the code easier to read, understand, review, and maintain.

## 1. Use `snake_case`

Variable and function names should normally use lowercase words separated by underscores.

```python
user_name = "Movsum"


def calculate_total(price, quantity):
    return price * quantity
```

Avoid unclear names:

```python
x = 10
```

Prefer descriptive names:

```python
user_age = 27
```

## 2. Use Four Spaces for Indentation

Python uses indentation to define code blocks.

```python
def greet(name):
    print("Hello", name)
```

Use four spaces for each indentation level. Do not mix tabs and spaces.

## 3. Add Spaces Around Operators

```python
total = price + tax
result = number * 2
is_adult = age >= 18
```

Avoid:

```python
total=price+tax
```

## 4. Use Blank Lines

Use blank lines to separate logical sections and functions.

```python
def add(a, b):
    return a + b


def multiply(a, b):
    return a * b
```

## 5. Keep Names Clear

Good names explain the purpose of the value or function.

```python
failed_login_count = 5
```

Less clear:

```python
flc = 5
```

## 6. Keep Code Readable

Readable code is more important than writing the shortest possible code.

```python
full_name = first_name + " " + last_name
```

## What I Learned

- PEP 8 is Python's style guide
- Variables and functions commonly use `snake_case`
- Python normally uses four spaces for indentation
- Spaces and blank lines improve readability
- Clear names make code easier to maintain
